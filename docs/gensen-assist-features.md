# ポケスリ厳選サポーター：機能仕様

## ゲームロジックの前提理解

- ポケモンはおてつだいで最大3種類の食材を持ってくる（種類はポケモンごとに固定）
- 持ってくる食材の種類が少ないほど、1種類あたりの量が多くなる
- プレイヤーは欲しい食材を持ってくるポケモンを厳選して捕まえる
- 良いポケモンが手に入った食材 = 「厳選済み」
- レシピは食材を一定数使うと自動的に解放される
- なべ容量 = 一度に投入できる食材の合計数（容量が大きいほど高難度レシピが作れる）

## MVPの前提（簡略化）

> チェック済みの食材は**無限に供給される**とみなす。
> = その食材を使うレシピは、なべ容量が足りていれば必ず作れる。

ただし「無限供給」が成立するのは、そのポケモンの**食材A（1枠）またはB（2枠）**として持ってくる場合のみ。

| 食材候補 | 解放Lv | MVPでの扱い |
|---------|--------|------------|
| A（1枠） | Lv.1 | ✅ チェック対象 |
| B（2枠） | Lv.30 | ✅ チェック対象 |
| C（3枠） | Lv.60 | ❌ 対象外（量が少なく不安定） |

ポケモン提案時も、必要な食材を**AまたはBとして**持つポケモンのみ表示する。Cのみのポケモンは除外。

> 個体差（持ってくる量の多少）はMVPでは考慮しない。全19食材をMVP対象とする。

---

## MVP 機能一覧

### 機能1: 食材厳選状況の入力

- 食材19種類をチェックボックスで一覧表示（食材名の先頭に絵文字付き）
- チェックあり = その食材を持ってくるポケモンの厳選が完了
- チェックなし = まだ厳選が必要
- 全選択・全解除ボタンあり（どちらも確認ダイアログ付き）
- 入力状態はローカルストレージで保持（ページを閉じても消えない）

### 機能2: なべ容量の入力

- スライダーで入力（15〜81、step=3）
- いいキャンプチケット トグルONでなべ容量を1.5倍（四捨五入）して計算
- チケットON時はスライダー上部に「現在値 → 適用後」を矢印で表示
- 入力状態はローカルストレージで保持

### 機能3: 現在作れる最大エナジーレシピの表示

- カレー・サラダ・デザートの3カテゴリを横並びで表示
- 各カテゴリで現在チェック済み食材 × なべ容量で作れる最大エナジーレシピ名・エナジー・必要食材一覧・合計個数を表示
- 作れるレシピがない場合は「作れるレシピなし」と表示

### 機能4: 厳選すべきポケモンの提案（メイン機能）

- 機能1・2の入力を元に計算
- 「未チェックの食材」ごとに「その食材をチェックしたと仮定」してスコアを計算
- スコア = カテゴリ別（カレー・サラダ・デザート）の最大エナジー合計の増加量
  - カテゴリは週替わりで独立しているためカテゴリをまたいだ比較はしない
- 優先度:
  - 高（high）: スコア1位の食材
  - 中（medium）: スコア2〜3位の食材
  - 低（low）: それ以降
- ポケモン表示: 進化系統を1カードにまとめる。枠表示はAAA（A枠）/ ABB（B枠）
- カードをタップすると、追加によってエナジーが上がるカテゴリのレシピ詳細を表示
- 全カテゴリで追加してもエナジーが増えない状態（すでに最大）ではトロフィーアイコンと達成メッセージを表示

## MVP 以降の追加候補（後回しOK）

| 機能 | 内容 | 優先度 |
|------|------|--------|
| レシピ一覧表示 | 現在のなべ容量で作れる/作れないレシピを一覧表示 | 中 |
| 達成率の表示 | 食材厳選の進捗をパーセントで表示 | 低 |
| マップ別フィルター | 現在いるマップに出現するポケモンに絞って提案 | 中 |
| ポケモン詳細リンク | 提案ポケモンをwikiへリンク | 低 |
| データ更新対応 | ゲームアップデートに合わせてデータを更新できる仕組み | 高（運用上） |

---

## 必要なデータ（MVP）

| データ | 内容 | 状態 |
|--------|------|------|
| 食材一覧 | 19種類の食材名・エナジー | ✅ data/ingredients.json |
| レシピ一覧 | カレー・サラダ・デザートの料理名・必要食材・合計個数・エナジー | ✅ data/recipes-*.json |
| ポケモン×食材対応表 | 各ポケモンのA/B/C枠食材・タイプ・食材得意フラグ | ✅ data/pokemon.json |

※個体差（持ってくる量）はMVPでは不要。食材の「種類」だけあればよい。

---

## データフロー

```
ユーザー入力
├── 食材チェックボックス（19種）→ 厳選済み食材IDの集合
└── なべ容量スライダー（15〜81）+ いいキャンプチケットトグル → 実効なべ容量

↓ ツールが計算（useMemo）

[機能3] カテゴリ別ベストレシピ
  カレー / サラダ / デザートそれぞれで最大エナジーレシピを表示

[機能4] 推薦ロジック
  未厳選の食材ごとに仮追加してカテゴリ別合計エナジー差分を計算
  → 差分の大きい順にランキング → 優先度（high/medium/low）付与
  → 進化系統グループ単位でポケモン提案を表示
```
