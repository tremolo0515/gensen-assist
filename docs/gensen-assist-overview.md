# ポケスリ便利ツール：概要

## コンセプト

> プレイヤーの現在の進行状況を入力すると、「今厳選すべきポケモン」を提案してくれるWebツール

---

## ツールの入力・出力

### インプット（ユーザーが入力）

- 現在の鍋容量
- 解放済みレシピの一覧（チェック形式）

### アウトプット

- 今厳選すべきおすすめポケモン（優先度付き）
- 現在の進行状況のUI表示（どのレシピが作れるか、何が足りないか）
