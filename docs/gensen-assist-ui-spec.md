# ポケスリ厳選サポーター：画面仕様

> v0.dev へのインプット・MVP実装の設計書として使用する。

---

## 全体構成

- **ページ数**: 1ページ（シングルページアプリ）
- **レイアウト**: 縦1カラム。スマホ・PC両対応（レスポンシブ）
- **スタック**: Next.js + Tailwind CSS
- **データ保存**: LocalStorage（サーバー不要）

---

## ページ全体レイアウト

```
┌─────────────────────────────┐
│  ヘッダー（タイトル）         │
├─────────────────────────────┤
│  セクション1: なべ容量の設定    │
├─────────────────────────────┤
│  セクション2: 食材チェック     │
├─────────────────────────────┤
│  セクション3: 厳選提案        │
└─────────────────────────────┘
```

## セクション詳細

---

### ヘッダー

| 要素 | 内容 |
|------|------|
| タイトル | 「ポケスリ厳選サポーター」 |
| サブテキスト | 「今のなべ容量と厳選済み食材を入力して、次に捕まえるべきポケモンを確認しよう」 |
| デザイン | シンプル。ポケスリらしい青系カラー |

---

### セクション1: なべ容量の設定

**目的**: 現在の鍋の容量を入力する

| 要素 | 仕様 |
|------|------|
| ラベル | 「🍳 鍋の容量」 |
| 入力方式 | ドロップダウン or 数値入力（15〜100の整数） |
| デフォルト値 | 15 |
| 補足テキスト | 「なべ容量は自分のレベルに応じて変化します」 |
| 保存 | LocalStorageに即時保存 |

---

### セクション2: 食材チェック

**目的**: 厳選済みの食材をチェックする

| 要素 | 仕様 |
|------|------|
| ラベル | 「✅ 厳選済みの食材」 |
| 説明テキスト | 「持ってくるポケモンの厳選が完了した食材にチェックを入れてください」 |
| 表示形式 | チェックボックス付きカードのグリッド（3〜4列） |
| 各食材カード | 食材名（日本語）+ チェックボックス |
| チェック状態 | チェックあり = 緑色で強調。チェックなし = グレーアウト |
| 保存 | LocalStorageに即時保存 |
| リセットボタン | 「全解除」ボタンあり（確認ダイアログあり） |

**食材一覧（全19種）:**

```
あまいミツ / あたたかジンジャー / リラックスカカオ / とくせんタマゴ
モーモーミルク / とくせんリンゴ / めざましコーヒー / ぐっすりトマト
わかくさコーン / ほっこりポテト / ピュアなオイル / わかくさダイズ
ふといナガネギ / じゅくせいキノコ / ぴかぴかリンゴ / ゆめのかけら
うましおのみ / ビッグマリルのしっぽ / げきからハーブ
```

※実際のIDは `ingredients.json` に準拠する

---

### セクション3: 厳選提案

**目的**: 入力内容をもとに「今厳選すべきポケモン」を提案する

| 要素 | 仕様 |
|------|------|
| ラベル | 「🎯 次に厳選すべきポケモン」 |
| トリガー | セクション1・2の変更に連動して**自動で再計算**（ボタン不要） |
| 未入力時 | 「食材となべ容量を入力すると提案が表示されます」というプレースホルダー |

**提案リスト（1件あたりの表示内容）:**

| 要素 | 内容 |
|------|------|
| ポケモン名 | 日本語名 |
| 持ってくる食材 | A枠・B枠の食材名（アイコンまたはテキスト） |
| 優先度バッジ | 「この食材が必要なレシピ数」をもとに高/中/低 |
| 理由テキスト | 「○○を持ってくる（現在未厳選）」 |

**空状態（全食材チェック済み）:**
- 「🎉 すべての食材が揃っています！」と表示

**提案なしの状態（条件に合うポケモンが存在しない）:**
- 「現在のなべ容量では、未厳選の食材が必要なレシピに届きません。なべ容量を上げると提案が表示されます」

---

## インタラクション仕様

| 操作 | 動作 |
|------|------|
| 食材チェックON/OFF | 即時再計算 → 提案リスト更新 |
| なべ容量変更 | 即時再計算 → 提案リスト更新 |
| ページ再訪問 | LocalStorageから状態を復元 |
| 全解除ボタン押下 | 確認後、食材チェックを全て外す |

```
Next.js + Tailwind CSS でポケモンスリープの厳選サポートツールを作ってください。
ツール名は「ポケスリ厳選サポーター」です。

- シングルページ。縦1カラム。スマホ・PCレスポンシブ対応。
- ヘッダー → セクション1 → セクション2 → セクション3 の順に縦並び。

---

【ヘッダー】
- タイトル: 「ポケスリ厳選サポーター」
- サブテキスト: 「なべ容量と厳選済み食材を入力して、次に捕まえるべきポケモンを確認しよう」
- 落ち着いた青・紫系のカラーパレット。ポケモンスリープらしい穏やかな雰囲気。

---

【セクション1: なべ容量の設定】
- ラベル「🍳 現在のなべ容量」
- スライダー or ドロップダウンで 15〜81 の整数を選択（ゲームの実際の範囲）
- デフォルト値: 15
- 現在の値を大きく表示（例: 「現在: 30」）
- LocalStorageに即時保存

---

【セクション2: 食材チェック】
- ラベル「✅ 厳選済みの食材」
- 説明文: 「担当ポケモンの厳選が完了した食材にチェックを入れてください」
- 以下の食材19種をチェックボックス付きカードのグリッドで表示（スマホ3列・PC4列）:
  あまいミツ / あんみんトマト / ほっこりポテト / あったかジンジャー /
  リラックスカカオ / げきからハーブ / ピュアなオイル / マメミート /
  モーモーミルク / とくせんエッグ / とくせんリンゴ / あじわいキノコ /
  ふといながねぎ / おいしいシッポ / ワカクサ大豆 / ワカクサコーン /
  めざましコーヒー / ずっしりカボチャ / つやつやアボカド
- チェック済み: 緑色でハイライト。チェックなし: グレーアウト。
- 右上に「全解除」ボタン（確認ダイアログあり）
- LocalStorageに即時保存

---

【セクション3: 厳選提案】
- ラベル「🎯 次に厳選すべきポケモン」
- セクション1・2の変更に連動して自動再計算（ボタン不要）

提案カードのレイアウト（1件あたり）:
┌─────────────────────────────────────┐
│ [優先度バッジ 高/中/低]                │
│ ポケモン名（例: カモネギ）             │
│ 担当食材: ふといながねぎ（A枠）        │
│ 解放できるレシピ: からくちネギもりカレー │
│ 獲得エナジー: 5,900                   │
└─────────────────────────────────────┘

- 優先度バッジ: 解放レシピのエナジーが高い順に「高（赤）」「中（黄）」「低（青）」
- ダミーデータで3〜5件表示（実装時に差し替え）

空状態（全食材チェック済み）:
「🎉 すべての食材が揃っています！おめでとうございます。」

提案なし状態（なべ容量が足りない）:
「現在のなべ容量では、未厳選の食材が必要なレシピに届きません。なべ容量を上げると提案が表示されます。」

【データ保存】
- なべ容量・食材チェック状態をLocalStorageで保持（ページ再訪時に復元）

【デザイン】

- フォントは読みやすい日本語対応フォント
```
